# 问询前哨：上市公司年报问询风险预警原型

这是一个面向“北京市大学生数智会计创新应用竞赛”的 Streamlit 原型。系统上传上市公司年报 PDF 后，自动抽取关键财务线索，识别可能触发交易所问询的风险点，并生成结构化风险表、问询问题、审计核查程序和可下载报告。

## 技术线

- Python + Streamlit：网页演示原型
- PyMuPDF：年报 PDF 文本抽取
- pandas / numpy：指标整理与规则计算
- DeepSeek / 通义千问 API：生成问询问题、审计程序和复核意见
- 本地规则引擎 + 案例库：无 API Key 时也能完成演示

## 快速运行

最简单的方式：双击项目目录里的 `start_app.cmd`。它会在后台启动本地服务并打开浏览器；关闭 Codex 或命令窗口不会自动关闭服务。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
streamlit run app.py
```

停止服务可以双击 `stop_app.cmd`。

如果暂时没有模型 API Key，可以在侧边栏选择“演示模式”。演示模式不会联网，会用内置规则和模板生成结果。

如需读取真实年报 PDF 并导出 PDF 报告，再安装增强依赖：

```powershell
pip install -r requirements-full.txt
```

## 推荐演示流程

1. 选择“使用内置演示年报摘要”快速跑通。
2. 点击“开始多智能体分析”。
3. 展示风险总览、风险明细、相似问询案例和量化评估。
4. 下载 JSON / CSV / Markdown / PDF 报告作为结构化提交物证据。
5. 换成真实年报 PDF，展示系统能处理真实样例数据。
6. 在侧边栏上传另一期报告，查看关键指标变化和风险证据页码。

## 升级模块

- 证据链：风险点绑定原文摘录、页码、来源文件和可信度状态；关键词命中会标记为“待核验”。
- 多期对比：可选上传同一公司的另一份报告，生成收入、利润、现金流、应收账款、存货、毛利率和资产负债率变化表。
- 字段质量诊断：保留字段完整度、正文信号、页码证据覆盖率和案例匹配覆盖率，避免把字段不足误读为无风险。

## 数据合规说明

应用只处理用户上传文件和本地示例数据，不内置真实公司负面结论。正式参赛时，请从巨潮资讯网、上交所、深交所、证监会公开页面补充真实年报、问询函和处罚决定书，并在方案书中列明来源。

## 作品定位

本系统不判断企业是否存在舞弊，也不构成投资、审计或法律意见。系统输出均为“AI 生成”的辅助分析，用于帮助上市公司、审计团队或课程教学场景提前发现披露风险并组织核查程序。
